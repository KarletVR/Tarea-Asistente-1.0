¿Cómo funciona?

Utiliza SpeechSynthesis, una interfaz de la Web Speech API que permite al navegador sintetizar voz. Las voces dependen del dispositivo y del navegador.

Acerca de la simulación

Este módulo representa una llamada mediante cambios de pantalla, controles interactivos y mensajes hablados generados con SpeechSynthesis. La voz se reproduce desde el dispositivo. No se conecta con la red telefónica ni utiliza el micrófono.

Acerca del proyecto

Conoce el propósito y las tecnologías de Tarea Asistente 1.0.

¿Qué es Tarea Asistente 1.0?

Es una aplicación web progresiva que reúne seis herramientas interactivas en una sola interfaz. Su propósito es demostrar el uso de distintas capacidades disponibles en los navegadores modernos mediante tecnologías web.

01Accesibilidad

Interfaz clara y adaptable a distintos tamaños de pantalla.

02Interactividad

Controles para utilizar cada herramienta de forma sencilla.

03Experiencia PWA

Instalación compatible y almacenamiento de recursos básicos en caché.
